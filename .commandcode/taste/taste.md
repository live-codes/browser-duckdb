# Taste

## Workflow

- Prefers scaffolding a minimal proof-of-concept (e.g. a single self-contained HTML page) before wiring a feature into the main codebase/framework integration. Confidence: 0.6

## Architecture / Constraints

- Favors fully client-side, serverless execution (browser + WebAssembly) over anything requiring a backend to run code. Confidence: 0.6
